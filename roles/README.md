# 角色（人格）文件

每个 `.md` 就是一个角色，文件名即角色名（去掉 .md）。机器人在群里发：

```
/roles            # 看有哪些角色
/role 毒舌群友     # 切到这个角色（写回 config.json 的 ai.role，重启不丢）
/role off         # 清除角色，回到 config.json 里的 ai.system 默认人格
```

只有管理员能用（群里 role 为 owner/admin 的人，或 `config.json → admin.owner_qq` 里填的 QQ 号）。

写法建议：
- 第一行给名字和身份，模型会以为那是它自己。
- 后面写"怎么说话"和"什么不做"，短句、具体、可执行，别写形容词堆砌。
- 小模型听不懂"适当配图"这种自由裁量的话，要么明确允许要么明确禁止。
- 想要它像群友不像客服，就明确写"没人点你可以潜水"。
