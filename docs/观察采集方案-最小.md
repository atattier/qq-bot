## 二、拟新增的三个字段（最小集）

### 字段 1：工具参数（P0，必须）
- **改**：bot.py:5893 一行
  ```python
  # 现在
  log.info("工具调用[%s] %s -> %s", name, fn, _tool_json(result)[:140])
  # 改为
  log.info("工具调用[%s] %s(%s) -> %s", name, fn, _tool_json(args)[:200], _tool_json(result)[:140])
  ```
- **目的**：参数完整率/正确率、错参数归因
- **隐私**：args 含用户画图描述、记忆查询词——与现有日志同敏感级；**仅本机 bot.log**，不上传、不进群、控制台不展示原文。日志中已有的消息正文同级别。

### 字段 2：消息属性（P0，必须）
- **改**：bot.py:16838 一行
  ```python
  log.info("%s %s user=%s(%s) at=%s img=%d qmid=%s: %s", ...,
           str(bool(at_self)), len(imgs or ()), str(qmid or 0), text[:60])
  ```
  （`at_self/imgs/qmid` 在该函数作用域内均已有变量）
- **目的**：判定"机器人是否被点名"→ 区分"该回没回"（漏）与"不该回却回了"（误）

### 字段 3：画图受理参数（P1，强烈建议）
- **改**：`现画排队` 日志行（bot.py:9600 附近 `draw_submit` 尾部）
  ```python
  log.info("现画排队 group=%s by %s engine=%s brief=%s edit=%s: %s",
           gid, who, engine or "", bool(brief), bool(edit), what[:40])
  ```
- **目的**：画图域参数质量（本轮重点域）
