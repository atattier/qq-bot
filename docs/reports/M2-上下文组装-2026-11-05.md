每段审计字段：`id / title / source / priority / critical / kind / status / chars / reason`；
`status ∈ included | empty | disabled | truncated | dropped_budget | error`。
`ModelContext.to_dict()` 只含段元数据与预算，**不含段正文**，落在影子 JSONL 里不会把人格/记忆原文写进审计文件。

### 1.2 预算与回退规则

- 超预算：只丢**非关键**段，从优先级数字最大的开始；每丢一段写 warning。
- 关键段永不因预算静默丢弃；关键段本身超预算时 `over_budget=true`、`overflow_reason=critical_exceeds_budget` 并写 warning。
- 可选段超过单段上限：截断并标 `truncated` + warning。
- provider 抛异常：该段标 `error` + warning，其余段照常组装，整轮不崩。
- Assembler 整体异常：`Core` 回退 M1 `build_messages`，`Decision.context={}`，并写“回退 legacy”告警。
- 逐段回退：`arch.context_disabled=["mood", ...]`；整段回退：`arch.context=legacy`（或 `QBOT_ARCH_CONTEXT=legacy`）。

### 1.3 媒体跨轮

`MediaIndex` 只存 `MediaRef` 引用，不读字节、不跨会话：

- 本轮图与引用图**永远带上**（不截断，n 只限制补进来的历史媒体条数）；
- 只有正文出现「这张/那张/刚才/引用/截图/看图…」等指代词时，才补本会话最近 Turn 的媒体；
- 每条带 `media_id / kind / origin / status / turn_id`，可回溯到哪一轮。

## 5. 已知限制（交给 M3 及以后）

1. **媒体只有引用**：`MediaRef` 不带字节、不带 caption；M2 只解决“哪张图属于哪一轮/哪个会话”，真正看图仍由后续 MediaStore 负责。
2. **跨轮缓存只在内存**：影子重启后最近 8 轮与媒体索引清零；不落盘是刻意的（避免影子写生产 state）。
3. **预算是字符数不是 token**：24000 字是保守上限，与各家 token 计费口径有偏差；真实成本仍由 M3/live 前实测。
4. **`external_evidence` 不联网**：链接速览/搜索会读外网，M2 影子明确不触发，只保留本地梗百科。
5. **provider 读的是活状态**：在 worker 线程里读记忆/心情/聊天缓存，读到的可能比 Turn 发生时稍晚；这是只读近似，不影响发送。
6. **默认仍 legacy**：`arch.context=legacy`，需主人验收后再决定是否在影子默认开 `assembler`；生产 `arch.shadow` 仍为 false。
7. **私聊没有 `recent_context`**：私聊上下文由 Turn 历史承担（群聊缓存不含私聊，符合隔离要求）。
