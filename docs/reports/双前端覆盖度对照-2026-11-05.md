# /admin 与 /console 功能覆盖度对照清单（2026-11-05）

主人裁决：**维持双前端并行过渡**（阶段 C 方案 §3 第 1 项 + 就寝前 5 项默认决定），本清单只做现状对照，**不下线 /admin**。真正的下线条件由 12f 定义：console 覆盖清单全绿 + 一周稳定期 + 主人拍板时间表。

## 6. 现有守卫覆盖边界（诚实说明）

`tests/_tconsole.py` 证明的是：页面壳/token 注入、静态资源 MIME 与路径穿越防护、/api 401 门与 config 结构、persona 过滤、meme 端点、旧 /admin 三条锚点。它**不证明**两个前端功能等价，也**不证明**任何 LLM/生图/发送的真实业务结果；`tests/_ta.py` 更是只有 print 冒烟、零断言，只能证明「路由能调通不崩」。本清单是静态源码对照，未做真人端到端点击验收——这正是「下线前一周稳定期」不能省的原因。
