# 阶段 C：重构方案（2026-11-05）

依据：[全仓审计-2026-11-05.md](全仓审计-2026-11-05.md)（P0×4 / P1×26 / 非问题裁决）。
本方案**只设计不实施**；每个单元待批准后按治理规程阶段 D 的 12 步流程独立执行（Git 状态检查→基线→实施→diff 审查→针对性测试→SAFE 回归→独立 commit→推送验证→证据输出）。

## 0. 全局原则

1. **每个单元 = 一串同主题 commit，可单独 `git revert` 回滚**；单元内不混入无关改动。
2. **不新增无意义抽象**：优先"移动 + 收敛"，其次才是"抽取 + 注册表"；凡能用一个列表/一个参数解决的，不建框架。
3. **功能行为零变化**为默认验收线（拆分类单元）；只有明确标注"行为变更"的单元才允许改行为，且单独列出。
4. 测试门槛：每单元跑 SAFE 全量（56+ 项）+ 单元针对性测试；涉及生产配置/重启的单元加跑 MANUAL 相关项。
5. 推送依赖 **U0**（GitHub 恢复）：U0 完成前，所有 commit 只落本地，不谎称已备份。
