## 3. 控件类型、保存方式、高级参数归属（现状盘点）

| 类型 | 控件 | 保存方式 | 归属 |
|---|---|---|---|
| bool | 开关（aria-checked 驱动） | 即点即存 POST {key,value:"开/关"} | 主区 |
| enum ≤4 项 | seg 分段 | 即点即存 | 主区 |
| enum >4 项 | select 下拉 | change 即存 | 主区 |

**拉取/测速的既有后端与 /admin 行为**（只接线，不动后端）：
- 「拉取」：`it.picker=true` 的项显示按钮 → GET `/api/custom_models`（识图模型带 `?vl=1` 只筛视觉模型）→ 弹清单点选 → POST {key, value: picker_prefix+model}。当前带 picker 的项：**「识图模型」**（picker_vl=true）与「模型选择」（picker_brain=custom，仅大脑=custom 时显示按钮——bot.py knob_items 的 picker 字段按当前大脑动态置位）

### 9.3 修订③：未保存输入状态流转

| 状态 | 触发 | 视觉 | 行为 |
|---|---|---|---|
| 干净 | 初值 / 保存成功 | 普通边框 | — |
| 已改未保存(dirty) | 输入值 ≠ 初值 | 边框转 warn 琥珀色 + 保存按钮实心 | — |
| 保存成功 | 点保存且 POST ok | 短暂绿框回落 + toast | dirty 清除、初值更新为新值 |
| 保存失败 | POST 失败/网络错 | 红色 toast | **输入保留原样（仍 dirty）**，不回滚文本 |
| 离开拦截 | 切分类/切分区/搜索跳转时存在 dirty | 确认弹窗：「有 N 项改动未保存——[留下保存] [放弃离开]」 | 明确选择放弃才丢弃 |
| 刷新/关页 | 存在 dirty | beforeunload 原生确认 | 浏览器托管 |
| 搜索定位 | 输入搜索词 | 只滚动+高亮+展开折叠 | **绝不改写/重置任何输入框的值**（过滤仅作用于显示层） |

实现约束：dirtyMap 按旋钮 key 记账；搜索/分类切换不重建输入框 DOM（复用现有"只切显示"模式）。

### 9.4 修订④：picker 完整接口契约与验收

**字段（bot.py `knob_items()` 现状，运行时动态置位）**：
| 字段 | 含义 | 当前带此字段的项 |
|---|---|---|
| `picker` | 显示「拉取/测速」按钮。`bool(picker) or (picker_brain == 当前大脑)` | 「识图模型」（恒有）、「模型选择」（大脑=custom 时有） |
| `picker_vl` | 拉取时只筛视觉模型（`?vl=1`） | 识图模型 true |
| `picker_prefix` | 选中后拼接前缀 | 两者均 `"custom/"` |

**拉取链**：
1. `GET /api/custom_models[?vl=1]`（header X-Bridge-Token）→ 成功 `{ok, models:[id…]}`；失败 `{ok:false, error}`（error 例：「先填『自定义API 地址』」「地址要以 http(s):// 开头」——**弹窗内红字显示，不关窗不写值**）
2. 列表渲染 → 用户点选一条 id
3. `POST /api/config {key: it.key, value: picker_prefix + id}`
4. `load()` 刷新后断言 `it.value === picker_prefix + id`（值一致）
5. 401 → 密钥卡（全局已有）

**测速链**：
1. `GET /api/probe_model?key=<it.key>` → 成功 `{ok, provider, model, chat:{sec,first,text,chunks,…}, vision?:{text|error}, verdict, advice}`；失败 `{ok:false, error:"连不上：…"}`（key 为本地 CLI 档时报「不是 API 档，没有模型测速」）
2. 展示契约：**verdict 一行人话结论为主展示**（后端已组好句，如「通，看图也对（…），但首字偏慢（4.07s）」）+ advice 次行；数字细节（首字 `chat.first`s / 总耗时 `chat.sec`s / 正文预览 `chat.text` 前 40 字）小字注脚——**字段名以本契约为准，前端不再自造**
3. 测速中按钮 disabled + 文案「测速中…」；失败红色 toast
4. 测的是**当前框里选中的值**（读 config 现值，同 /admin 语义）

**验收步骤（两条链全走）**：
- 拉取：系统设置→大脑与模型→「模型选择」点拉取 → 清单出现 → 点选一个 → toast 成功 → 刷新页面值 = `custom/<所选>` → /admin 同项显示一致
- 识图模型：识图分类点拉取（应只出视觉模型清单）→ 选一个 → 同上断言
- 测速：对「模型选择」点测速 → toast 出 verdict+advice → 断开网关地址再点 → 红色「测速失败：连不上…」
- 边界：大脑切到 qoder → 「模型选择」旁不再出现拉取/测速按钮（picker_brain 条件）
