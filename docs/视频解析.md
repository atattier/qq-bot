## 7.7 视频解析：B站 / 抖音链接 → 无水印视频发回会话（2026-09-17 上线）

主人原话：「加一个解析群里发送的B站或者抖音链接，然后发送无水印的视频文件到群里的功能，
这个github上应该有方法，你照抄就行。」照抄的是开源社区标准做法 **yt-dlp + ffmpeg**，
不是来路不明的"去水印网站"（那些站会二次压缩画质、记你的链接）。

- **代码**：`videoparse.py`（解析/选流/下载）+ `bot.py` 里的
  `handle_video_link` / `_do_video` / `_vid_worker`（队列，跟现画一个套路，不堵上报线程）。
- **依赖**（都是 pip 包，已装）：`yt-dlp`（引擎）、`imageio-ffmpeg`（提供 ffmpeg 二进制，
  B站 480P 以上是 DASH **音视频分离**流，必须 ffmpeg 合并）。
- **触发**：群里或私聊里**发链接即可**，不用 @、不用前缀。识别挂在关键词规则**之前**
  （发链接是很明确的意图，不能被关键词抢答）。支持 B站（`BV`/`av`/`b23.tv`/番剧）与
  抖音（`v.douyin.com` 短链 / `douyin.com/video` / `note` / `iesdouyin`）。
  **协议头可省**（"www.douyin.com/xxx" 也认），尾巴的中文句号会自动剥掉。

### ⚠️ 选流铁律（画质全靠这条，别用 yt-dlp 的默认 bestvideo）

**不能直接写 `bestvideo[height<=N]`**：yt-dlp 的 "best" 排序把**编码效率高的 AV1/VP9
排在 H.264 前面**，于是 `bestvideo[height<=720]` 在 B站会挑到 `100022`
（AV1 的 **360P** / 163kbps），而不是 H.264 的 720P（742kbps）—— 主人一眼就看出糊。
实测同一支视频：

| 写法 | 结果 |
|---|---|
| `bestvideo[height<=720]+bestaudio` | 360×640 AV1 163k / **2.8MB** |
| **pick_stream（H.264 优先 + 体积内最高画质）** | **1080×1920 H.264 1482k / 16.9MB** |

所以 `pick_stream()` 自己挑：排序键 =（**H.264 优先** → 分辨率高 → 码率高），
体积超 `video.max_size_mb` 的档跳过（长视频自动降档）。
H.264 优先是**为了 QQ 能播** —— AV1/HEVC 手机 QQ 不保证解码，播不了等于白下。

### 配置（`config.video`，网页「视频」分区，7 个旋钮）

`enabled` / `max_height`(默认 2160=不封顶) / `max_size_mb`(100，超了自动降档) /
`max_duration_sec`(600) / `cooldown_sec`(20) / `use_browser`(抖音兜底) / `cookie_file`。
缓存目录 `state/videos/`，`keep_hours`(6) 后自动清理。

### ⚠️ 抖音：现在必须真实浏览器或 cookie

2026-09-17 实测：纯 Python 请求 douyin.com **一定**被反爬挑战页拦掉 —— 返回
72914 字节、无 title 无可见文本的页面（特征含 `__ac_nonce`，要跑 JS 才解）。
yt-dlp 的表现是 `Fresh cookies (not necessarily logged in) are needed`。
匿名 `ttwid`（`ttwid.bytedance.com/ttwid/union/register/`）能拿到但**不够**，
detail 接口仍返回空。稳的两条路：① `use_browser=True` 时起 Playwright + 本机 Chrome 兜底；
② 主人从浏览器导出 cookies.txt 填进 `cookie_file`。
**B站不用这些也能跑**（1080P 直接拿）。

### 已踩的坑

- **同名文件已存在时 yt-dlp 会跳过下载**（默认不覆盖）→ 我的"下载前后 diff 找新文件"
  逻辑会误判成"下载完没找到文件"。修法：没有新文件就当**命中缓存**，直接复用旧文件。
- 探测阶段会先拿时长，超 `max_duration_sec` 连下都不下，省时间省流量。

**回归**：`tests/_tvideo.py`（全打桩，绝不真下载/真发消息，A–K 十一节：
链接识别 / 群私聊都认 / 总开关 / 冷却 / 配额 / 成功发 video 段 / 失败回人话 /
段结构合规 / 链接优先于关键词 / 普通文本不触发）。
