- **主体查证 SubjectBook**：描述里有角色名/历史人物/梗时，先联网搜设定卡喂给润色。卡片是**三行**（2026-09-14 加第三行）：`WHO:` 是谁 / `LOOK:` 英文外观 / `TAGS:` 一行 danbooru 角色 tag（全小写不带 @，写法＝完整全名+完整系列名+关键外观，供 tag 选配当角色串用，见下条）。**坑：别指望模型自己联网**，必须自己调 `web_search(query)` 拿 snippet 再喂；探测提示词必须点名"外号/账号名/UP主/品牌+普通词/'X的Y'的X"都算专有名词。**坑 2（2026-09-14）**：小模型会把自己的系统提示当输出吐回来（「照抄描述里的写法」「最多 3 个」），这种垃圾名会被当真去查、还把资料存进缓存污染整本书 → `_in_text()` 强制"挑出来的名字必须真出现在原文里"。缓存 `state/subjects.json`，管理员「画图 重查」清；加 TAGS 之前的旧卡片（无 `tags` 字段）下次会重查一次补齐，但官方目录认得的角色不重查（`_dex_character` 短路）。
