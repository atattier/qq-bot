## 1B-1. 四参数逐项审计（真实来源 → 消费点）

### `edit`（补全/改稿指令，str）
| 项 | 内容 |
|---|---|
| 定义与入队 | `draw_submit(..., edit=None)` bot.py:9571 → job["edit"] :9608 |
| 消费 | 仅 moss 分支：`do_draw` :10091 → `_moss_prompt(edit=…)` :8987 → `moss_layout.edit_draft(draft, edit, llm)`（改稿补丁，只改提到的地方） |
| 已支持的入口 | 群口令「moss改：」（:3240 edit=instruction）、网页 Moss 工具（ea8c6b7） |
| **大脑 `draw_image`** | ❌ 不支持（5698-5706 调用未传 edit） |
| 允许值 | 自由文本（中文即可，edit_draft 内部落英文）；默认 None |
| 组合冲突 | 仅 engine="moss" 且 i2i/what 存在时有意义；comfyui 分支**静默丢弃**（do_draw comfyui 分支不读 edit）——契约必须声明"仅 moss 链路生效" |

### `brief`（简易档，bool）
| 项 | 内容 |
|---|---|
| 定义与入队 | bot.py:9571 → job["brief"] :9609 |
| 消费 | 仅 moss 分支：`_moss_prompt(brief=…)` → `moss_layout.from_text/from_image(brief=)`（4~6 框简易布局，快一半） |
| 已支持的入口 | 沉浸情景模式（:11496 brief=True）、网页 Moss 工具 |
| **大脑** | ❌ 不支持 |
| 组合冲突 | 无（与 edit 正交：先 brief 出草稿，edit 打补丁） |

### `reverse_mode`（layout/hybrid/raw，str）
| 项 | 内容 |
|---|---|
| 定义与入队 | bot.py:9572 → job["reverse_mode"] :9610 |
| 消费 | 仅 moss i2i 分支：`_moss_prompt(reverse_mode=…)` :8995 → hybrid 时先跑 Caption 散文再 `from_image(prose=)`（05907a3 加）；layout/raw 的区分在 :8562 `_moss_layout_on()` |
| 已支持的入口 | 网页 Moss 工具（固定 "hybrid"） |
| **大脑** | ❌ 不支持 |
| 允许值 | layout / hybrid / raw；默认 None = 按 `moss.prompt_mode` 旋钮 |
| 组合冲突 | 与 `moss.prompt_mode` 旋钮的优先级：**job 显式值 > 旋钮**（契约须写明） |

### `detail`（反推详细程度 long/medium/short，str）
| 项 | 内容 |
|---|---|
| 定义与入队 | bot.py:9572 → job["detail"] :9611 |
| 消费 | 仅 moss i2i 分支：`from_image(detail=)` → `REVERSE_DETAIL[detail]` 注入视觉提示词 |
| 已支持的入口 | 网页 Moss 工具（83c51f） |
| **大脑** | ❌ 不支持 |
| 允许值 | long / medium / short；默认 medium；非法值 from_image 内部落回 medium（:344） |
| 组合冲突 | 无 |

### 结论
四参数**全部只在 moss 链路生效**；comfyui 分支不消费其中任何一个。大脑工具缺这四个 = 大脑画图永远走默认档。**这正是"大脑能力弱于口令"的参数面实锤。**

## 1B-2. 统一工具契约（设计）

### `draw_image`（扩展，向后兼容——新增参数全可选）
```json
{
  "name": "draw_image",
  "parameters": {
    "what":  {"type": "string", "required": true, "desc": "画面描述"},
    "style": {"type": "string", "required": false, "desc": "本地档（厚涂/krea2/anima/宫格）；给了走 ComfyUI"},
    "aspect":{"type": "string", "required": false, "desc": "长宽比 16:9/1:1/9:16"},
    "brief": {"type": "boolean", "required": false, "desc": "moss 简易档（4~6框，快一半）"},
    "edit":  {"type": "string", "required": false, "desc": "moss 补全/改稿要求（仅 moss 链路生效）"},
    "detail":{"type": "string", "required": false, "enum": ["long","medium","short"],
              "desc": "moss 反推详细程度（仅 i2i/hybrid）"}
  }
}
```
### `draw_like_this`（扩展）
```json
{
  "name": "draw_like_this",
  "parameters": {
    "extra": {"type": "string", "required": false, "desc": "改动要求（moss edit_draft 打补丁）"},
    "style": {"type": "string", "required": false},
    "brief": {"type": "boolean", "required": false},
    "reverse_mode": {"type": "string", "required": false, "enum": ["layout","hybrid","raw"],
                     "desc": "反推模式；默认按「云端提示词模式」旋钮"},
    "detail": {"type": "string", "required": false, "enum": ["long","medium","short"]}
  }
}
```
### `cloud_draw`（扩展）
同 `draw_image` 去 style/aspect（云端无档位），加 `brief/edit`。

### 不给大脑的参数（有意排除）
- `reverse_mode` on draw_image：文生图不走反推（无参考图），语义不成立。
- `denoise`：ComfyUI 图生图相似度，属"能力实现参数"（提案 §6 第三类），策略层定。
- `lookup`：查设定开关是用户偏好，旋钮已有。

### 分派实现（阶段 1 编码量预估）
`_tool_dispatch` 5691-5740 处把四个新参数透传给既有 `draw_submit(...)`——**每工具 +3~5 行，无新逻辑**。资源闸/权限闸自动继承（draw_submit 内部四道闸）。

## 1B-3. 参考图来源规则（现状审计 + 契约声明）

| 场景 | 现状行为 | 代码位置 | 契约声明 |
|---|---|---|---|
| 本条消息带图 | `imgs[0]` 经 `_fetch_rev_image` 下载到本地 | handle_moss_reverse:3267 | 大脑 `draw_like_this` 只认"本轮参考图"（_TOOL_CTX.segs）——**不变** |
| 回复（引用）的图 | `qmid` → `quoted_images(qmid)[0]` | :3272 | 本条无图且引用有图时用——**不变** |
| 多张图 | **只取第一张**（imgs[0]） | :3267 | 契约写明"仅用第一张"；多图选择是后续能力，不在本契约 |
| 都没有 | 口令回"这张图我这边没收到" | :3280 | 大脑工具返回 `{"ok":false,"error":"这一轮没有参考图"}`（现状已如此） |
| 用户要"修改" vs "重新反推" | 修改 = `moss改：`/口语改图（edit_draft 打补丁）；重画 = `moss反推`（from_image 全新反推） | :3201/:3248 | 契约：`draw_like_this.extra` 非空 → 反推后走 edit_draft 补丁；为空 → 纯反推重画（与口令一致） |
| 反推 vs 画同款（comfyui） | i2i 有图：moss 引擎走 from_image，comfyui 引擎走 i2i_workflow+denoise | do_draw 分支 | 契约：`draw_like_this` 不带 style 时按会话引擎自动分流——**不变** |

### 评分口径
- **分支命中**：走没走预期分支（探针/出站断言）。
- **参数正确**：draw_submit 收到的 what/edit/brief/detail 与预期一致。
- **诚实性**：失败例（#13）回话必须含真实原因，禁止"已经在弄了"。
- 每例 0/1 分，试点门槛建议：首轮 ≥12/15，误执行（#9/10/11 判"执行"即失败）与漏执行（#1/4/6 刌"不执行"）**零容忍**。
