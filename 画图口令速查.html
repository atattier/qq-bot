① 画风怎么喊（五种句式都认）

句式例句
用X…用动漫画只猫 用写实画同款 用krea2画：城市夜景
句首 X＋画动词动漫画只猫 写实画一张城市夜景 Anima画只猫
逗号式
被@ / 私聊才认		 写实风景，中世纪高耸塔楼，尖顶，石头墙，阴影层次
风景，中世纪高耸塔楼 写真，一个女孩在雨里
动词在前式画写实风景，中世纪卢浮宫 画动漫，一个少女 画一张风景，山间小屋
括号式画[动漫]猫 画(写实)少女
句尾式画只猫 用动漫档 画同款 用krea2档
触发词表：写实 / 真人 / 摄影 / 照片 / 写真 → krea2 ｜ 动漫 / 二次元 / 日系 / 番剧 / 卡通 → anima ｜ 风景 / 山水 / 景色 → 写实风景 ｜ 快 / 草稿 → fast。 真档名 anima、krea2、写实风景 直接写也认。
逗号式只在被@/私聊时认：群里没@我时「风景，我觉得挺好看」这种闲聊不能被当成指令，所以不认； 分隔符必须是标点（，、：；），空格不算 ——「写实风景 中世纪塔楼」不认，得写成「写实风景，中世纪塔楼」。
底下那条老规矩没变：句中不认档位词——「画个动漫展的海报」「画动漫杂志封面」不会被误抢走档 （逗号式的正文还得像一段提示词：≥6 字、不带「你我吗」这类语气）。

② 三档画风线怎么工作（2026-09-30 主人定稿）

写实人物krea2

双工作流：文生图「Krea2_2.5D风格.json」；带参考图（画/画同款）换「Krea2_漫转写实真人V3.json」
漫转写实 = 把动漫原图转写实真人（i2i_denoise 80%）
文生图 ~135s / 画同款 ~104s ｜ 润色 = 自然语言长句

动画人物anima

主人工作流「Anima2.5D_恢复版.json」（anima 内核 2.5D 渲染）
尺寸预设 SDXL_832×1216 竖幅
能吃参考图（画同款）｜ 润色 = tag 行：画师 @ 开头

厚涂人物厚涂

主人工作流「Krea2_古风二次元.json」（krea2 turbo 底模 + 古风 LoRA 栈）
口语「厚涂 / 古风 / 古风二次元」都认
实测 ~165s ｜ 能吃参考图 ｜ 润色走 anima 口感
写实风景档已撤（09-30）；口语「写实/动漫/二次元/厚涂/古风」自动落对应档。

③ 图生图（画同款）

发图 +「画同款」→反推出提示词→认人（视觉模型） →拼上补充描述→参考图直进一采 latent→出图
说法效果
画同款照原图重画一张，相似度默认 60%
画同款 举着伞站在雨里想改动作/场景 → 自动放开到 75%（实测 60 改不动构图、75 才出得来新场景）
用动漫画同款换档图生图；档位解析优先落在真能吃参考图的档上，接不了的会明确回绝
反推完直接 画同款 描述刚反推过的图不用重发（15 分钟内有效）
相似度 = 画风旋钮：调 75~85 出底模自己的画风；45~55 复刻原图画风； 60 只换人物不改构图。在 /admin「反推」卡「同款相似度」里调。
2026-09-17 起图生图整条链路不碰豆包：参考图直接接进工作流一采 （日志「参考图已接进一采」），想恢复老的豆包识图认人，开 /admin「图生图豆包识图」即可。

⑤ 生成视频（2026-10-01 新，10-02 更新）

口令作用
生成视频 描述 / 做视频 描述 / 生视频 描述 H3 带声视频（成片 8 秒 @24fps）。描述就是片子的分镜+旁白—— 谁出场、做什么、什么氛围、说什么话，至少 10 字；H3 的音频由这段文本朗读出来。 ⚠️ 必须拼成一条发：分好几条发只认第一条
发图 + 生成视频 描述图当角色参考（当前工作流吃 1 张图）
发视频 + 生成视频 描述 ⚠️ 当前快链路（精简版工作流）没有参考视频输入，发了会明说用不上； 要动作/运镜参考得切回带参考链的老工作流（慢很多）
图 + 反推视频提示词 把一张图反推成 H3 视频提示词（7 秒左右出 3000+ 字，分段发回）； 拿到后 生成视频 + 那段提示词 即可出片
参考视频生视频 描述 / 参考图生视频 描述 同上的别名写法。⭐ 素材可以分条发：先发图/视频、再单独发口令—— 小鲸记得你前 30 分钟内发的素材（最近 8 张图 + 最后 1 段视频），口令没带就自动回捞； 只认你自己发的，别人的捞不到
视频 复位（管理员） 小鲸回「已经有视频在生成了」但其实没在跑（忙闸门卡住）时，发它松闸 + 清排队， 不用重启 bot
画图 启动ComfyUI 没开时管理员先拉起，再发视频口令
⚠️ 很重：本机 8G 显存硬扛 38G H3 模型（mmap），一条片约 10~15 分钟、 期间整机会卡——队列只排 1 个，冷却 0 秒 / 每小时 4 条（/admin →「视频生成」可调）。 成片帧率由小鲸强制 24fps，出片消息里会写「成片 X 秒 @24fps」，不对就是有问题。
