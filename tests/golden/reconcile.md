# M0 Golden Set 对账报告

日期：2026-11-05  
ADR：`docs/架构决策-统一智能核心-2026-11-05.md`（v1.0，`810d62a`）  
数据集：`tests/golden/golden_set.json`（240 条，sha256 见 `baseline.json`）

## 1. 分母

**240 条冻结样本**是唯一分母。所有覆盖率百分比都按 240 计算，不按“跑过多少条”或“模型答对多少条”重算。

## 2. 数据来源

| 来源 | 条数 | 占比 | 说明 |
|---|---:|---:|---|
| `real_observation` | 106 | 44.2% | 来自 `state/_obs_samples.json` 的真实消息/相邻多轮；已脱敏 |
| `known_failure` | 15 | 6.2% | 有文档/日志证据的已知失败案例（baseline=fail） |
| `known_test_case` | 119 | 49.6% | 依据 `bot.py` 工具契约、ADR 安全硬轨、既有测试与真实表达构建的场景；不是模型生成的回答 |

> 说明：权限越权、提示注入、不可逆操作、工具超时/异常、记忆写入拒绝等类别，在 3 天真实语料里没有足够多的“完整触发”样本。为了保证这些安全边界被固定下来，这部分使用有代码/文档依据的场景样本（`known_test_case`），并在每条 `source.ref` 里写明依据。它们不是随机编造，也不冒充真实聊天。

## 3. 排除项与理由

1. **`state/maimem.db` 的 `turns` 表整体不用于采样。** 该表含成人角色扮演内容，不满足 M0 的脱敏/安全标准；不把这类内容搬进评测集。
2. **排除 bot 自身与两个明确的机器人人格账号**（`who`/`uid` 维度的自对话），避免把模型自己的输出当成用户输入。
3. **敏感内容过滤**：成人、性暗示、暴力、自伤、证件/银行卡/密码/验证码/住址等命中即丢弃；不在数据集中保留原文。
4. **精确去重**：按去空白/标点后的文本去重；另做字符二元组近重复检查，超过 0.90 直接报错，0.80–0.90 仅告警并人工复核。当前最高一对为 0.857（两条短句，语义不同），已保留。
5. **长度限制**：输入文本限制在 110 字以内，避免把整段聊天记录当单条样本。
6. **图片**：只保留脱敏后的文字描述；`ref` 是样本内占位符，不指向真实文件或 URL。图片描述来自 `bot.log` 的真实识图输出（已脱敏）或公开的通用画面描述。

## 4. 脱敏

- 真实昵称、QQ 号、群号、群名、链接、邮箱、长串凭据 → `<U..>` / `<号码>` / `<链接>` / `<邮箱>` / `<长串>` 占位符。
- `run_eval.py --validate` 对每条样本检查：6 位以上裸数字、URL、邮箱、`Bearer`、`sk-`、`token=`/`password=` 等残留。当前 **0 命中**。
- 昵称替换基于只读加载的 `people`/`person` 名称表；替换只发生在构建阶段，数据集中不保留原名。
- 构建后人工通读 240 条文本，确认没有真实姓名、号码、住址、账号或凭据。

## 6. 已知失败案例（证据）

`source.kind=known_failure` 的 15 条，以及部分 `baseline=fail` 的真实观测，覆盖：

- **工具风暴 / qq_groups 滥用**：「画得挺像的」「路边一条呢柚大人」「你也去查下」「你这不对吧」——证据：`docs/观察报告-初稿.md` §7。
- **歌词误画**：歌词式文本被当画图描述——证据：同上 §7/§9（已脱敏改写，保留句式）。
- **无图反推/画同款**：「继续反推」「你画一个」「我要layout布局提示词」「我要你改成那个混合档」——证据：同上 §9；真实工具返回 `这一轮没有图/没有参考图`。
- **改稿请求迷路**：「帮我改下故事，我觉得文笔很ai」——证据：同上 §7/§9。
- **多图指代丢失**：「画这两个」「画上面那两幅画」——证据：`docs/reports/资产清理与架构重建审计-2026-11-05.md` §4.3①、`docs/reports/智能体架构审查-2026-11-05.md`（15:05:23 私聊 img=0 qmid=0）。
- **搜索重复**：「Trump 最近有什么新闻」「MiniMax 最新发布的模型是哪一款」——实测分别连搜 7/12 次；期望 `max_calls=1`。
- **上下文错位/风格反馈**：「这 bot 在回答之前的对话吧」「别这样发言，显得你像机器人」——证据：同上 §8。

## 7. 可重复性

```bash
python tests/golden/run_eval.py --validate --self-test
python tests/golden/run_eval.py --coverage
```

- 数据集是冻结 JSON；评测器只读本地文件，不联网、不启动 bot、不发送消息、不调用真实工具。
- `--self-test` 用 `expected` 生成 oracle，要求 240/240 通过；再对每条样本注入禁止动作/工具/内容、缺失必需工具、未知动作、空决策，要求全部被判失败。
- 覆盖率与 sha256 是确定性输出；没有随机数、时间依赖或真实网络依赖。

## 8. 已知限制

- 分类不是等量配额；`chat` 占比最高（23.3%），`tool`/`memory` 占比较低，原因是真实语料中完整触发这些意图的消息较少。
- `admin` 只有 11 条、`stranger` 只有 5 条（真实语料中这两个身份本身很少）；已满足最低要求，但不足以做分身份的统计显著性结论。
- 约一半样本是 `known_test_case`（场景样本），用于覆盖安全/失败/记忆边界；见 §2 的说明。M0 的目标是固定“正确/禁止”的判定基线，不是做模型准确率排行榜。
- 全量 SAFE 结果见 `TEST-RESULTS.md`：67/67 通过；M0 守卫只读，不联网、不发消息、不写 state。
